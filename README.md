# Deck Builder

Shared tooling for reproducible Anki deck generation across OpenDecksLibrary collections.

**Status: planned.** The initial generator will be prototyped in [Ultimate Hitster](https://github.com/OpenDecksLibrary/ultimate-hitster). Reusable components will be extracted here once their interfaces are validated.

## Planned scope

- Input validation and deterministic note identifiers.
- Anki note and template generation.
- Media reference validation.
- Reproducible packaging and release checks.
- Upgrade compatibility tests.

No installable package is available yet. Open an issue to propose shared requirements.
